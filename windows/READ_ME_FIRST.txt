Pitch Speed - Windows program

1. Unzip this folder anywhere you like (for example in Documents). Keep all the
   files together: the programs need the "_internal" folder next to them.
   (Or use PitchSpeed-Setup.exe from the same download page: it installs
   Pitch Speed with a Start-menu entry and a desktop icon.)
2. Open PitchSpeed.exe. Click "Add tapes..." (or drag video files onto the
   window), choose your league and speed graphic under Settings, then click
   "Mark pitches by hand".
3. Results go into a folder next to each video ("<video name>_pitchspeed");
   "Open results folder" shows it.

pitchspeed-cli.exe is the command-line program the window runs in the
background; you don't need to open it.

Windows may warn the first time ("Windows protected your PC"), because the
program is not signed: click "More info", then "Run anyway".

The full instructions (keys, marking by hand, the side-by-side view G) are in
README.md in this folder.

Pitch Speed - Windows program

1. Unzip this folder anywhere you like (for example in Documents). Keep all the
   files together: PitchSpeed.exe needs the "_internal" folder next to it.
2. To measure a tape: drag the video file onto PitchSpeed.exe.
   Several videos can be dragged at once.
   Tip: right-click PitchSpeed.exe > Send to > Desktop (create shortcut), and
   drag videos onto the shortcut.
3. Results go into a folder next to the video ("<video name>_pitchspeed").

Windows may warn the first time ("Windows protected your PC"), because the
program is not signed: click "More info", then "Run anyway".

The full instructions (keys, marking by hand, the side-by-side view G) are in
README.md in this folder.
